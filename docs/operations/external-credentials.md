# External credentials

Indexer, tracker, Usenet and subtitle accounts are intentionally not generated by
the repository. Enter only credentials for accounts you own.

## Through the Server Phim app

1. Open **Quản trị**.
2. Choose **Indexer**, **Download client** or **Subtitle provider**.
3. Keep the implementation name shown by the service schema and fill its settings.
4. Save. The app sends the values only to `127.0.0.1:11444`; responses and backend
   errors redact passwords, cookies, tokens and API keys.

The backend state file is `/srv/media-stack/appdata/media-control/admin.json`. It is
inside the isolated WSL filesystem and is created with mode `0600`. Do not copy this
file into Git, screenshots or support messages.

## Current readiness

- Torrent: qBittorrent is configured and is the default download client.
- Usenet: SABnzbd and all three Arr integrations are configured, but a Usenet server
  subscription is still required before downloads can start.
- Indexers: Prowlarr is linked to Radarr, Sonarr and Lidarr; tracker/indexer details
  still require the user's account or a legal public source.
- Subtitles: Bazarr is linked to Radarr and Sonarr. Configure a supported provider,
  prioritizing Vietnamese and retaining English as fallback.
- FlareSolverr: configured as an available Prowlarr proxy, not assigned globally.

After adding an account, use its health test in the app. Do not paste credentials into
the repository, Docker Compose, issue trackers or chat logs.
